# V94 性能与 IP 测试改动

本版基于 V93，保留设置面板四边同步插值和快/中/慢持久化偏好。

## 本版优化

- 静态壁纸（关闭色彩流动或三色相同）停止装饰时钟工作，不读取动态时间；可见动态壁纸恢复后延续原时间，不累计暂停时长。
- 凹槽壁纸按宽、高、逻辑高度和角度缓存几何。缓存仅保留当前一组，颜色流动复用几何。
- 策略 LIST 模式展开组改为按行惰性加载；保留 1–3 列、节点选择、组折叠和后续组可达性。
- 仪表盘 DNS 专用导航镜片读数移到叶子组件；快捷面板按当前内容订阅日志和流量，减少无关界面刷新。
- 请求日志解析与筛选移到 Default 工作线程，用最多 1000 项的 ID+内容缓存复用解析结果；只在 STARTED 生命周期收集，旧任务取消后不能覆盖新快照。
- 请求页实时速率读取独立 trafficMetrics 流；修复原生 level/message 日志信封识别。
- 设置、外观和玻璃效果滚动期间暂停背景装饰时钟；设置详情顶部渐显状态在达到上限后不再持续触发重组。

## IP 测试

入口：仪表盘 → IP 测试 → 配置 Scamalytics。

1. 手工输入账号和 API Key，或导入不超过 16 KiB 的 JSON。
2. 选择与账号一致的 API 节点（api11 US / api12 EU），点击“加密保存”。
3. 返回 IP 面板后手动点击“检测当前 IP”。打开面板与保存凭据不发起检测。
4. 可先开启“测试模式”验证接口；test=1 的结果仅用于验证接口，不作为实时风险结论。

JSON 示例只含占位值：

```json
{"username":"YOUR_USERNAME","api_key":"YOUR_API_KEY","endpoint":"api11"}
```

凭据通过 Android Keystore AES-GCM 在本机加密保存，不嵌入源码和安装包。密钥不会在重开设置时回显。替换时重新输入或导入，删除按钮可清除本机配置。个人凭据导入文件单独保管，不应并入源码或证据包。

VPN 运行时，出口 IP 和风险请求均走本地 HTTP 代理，不静默回退直连。请求可取消、不跟随重定向，错误信息使用本地固定文本。风险查询失败时保留本次已解析的出口 IP。未知和 Premium 占位字段分别显示，不将缺失值解释为“未命中”。

## 构建

要求 Android SDK 37、NDK 28.2.13676358、CMake 3.22.1 和可运行 Gradle 的 JDK。设置 ANDROID_HOME，或在本机 local.properties 配置 sdk.dir。

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest --no-daemon
```

Debug 安装包只含 arm64-v8a，使用既有独立测试包名 `com.github.arca.android.glasstest.fusion`。V94 为交付迭代名称，Android versionCode/versionName 沿用既有 87/1.1.0。

## 验证范围

最终回归计数和前后测量以交付验证报告为准。x86_64 软件渲染模拟器可验证界面、Android Keystore 操作与交互流程，不能代表 ARM64 真机帧率或证明真实 VPN 隧道行为。

本版未修改原生 Mihomo 核心及其配对库。已识别但未在本轮改动的项包括：原生停止的主线程成本、健康检查回调及 JNI 引用管理、日志生产端全缓冲快照，以及请求页累计流量仍来自 VpnState。不要将本版表述为所有 VPN/后台瓶颈均已消除。
