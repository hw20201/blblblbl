## 保留的设计

普通／明显／极致的色散强度分别为 **10.0／15.5／20.0**。这是原光学参数的强度单位，不是通道错开 10dp。普通档通过单侧额外红通道采样近似轻微色散；折射位移 1.2dp，通道位移上限约 0.24dp。三档不新增待机动画，也不新增整面磨砂。

B 模式按压不整体上移、不放大，边缘目标倾角最高 6°，点击区域固定，释放回正。独立的轮廓半影保持在原槽位。API 33+ 提供实时折射；API 31–32 仅背景重放和壳层；API 26–30 或低内存设备使用静态降级。低版本没有等价实时光学效果。

Backdrop 是保留授权说明的源码适配，**不是完整 Backdrop 依赖**。底部导航、背景配色、VPN 和原生库源码均未改动。

## 为真实构建补齐的内容

原补丁漏掉了 `MainActivity.kt` 的 `GlassDefaults` 导入，已补齐。原静态检查把任何 `build.gradle.kts` 变化都禁止，现仅允许版本字段及用户单独授权的单条 Lint baseline 接线，其他构建配置仍必须与基准相同。

旧预览测试要求 B 中心按压发生视觉变化，与新设计冲突：现在中心按压断言保持原位，真实按压响应改在边缘验证，仍检查 32ms 响应、固定命中区和手势取消。

新倾斜测试最初把 `localToRoot` 上下边透视差作为方向判据。实际 Robolectric 返回的矩阵只有正交投影，正反角的边长相同，但可观测对应轴收缩。现检查每个边缘确实引起非零前景收缩、正交轴保持、释放恢复尺寸、命中区固定及正常点击；倾角方向通过目标数值单独验证。**这不等于已验证真实设备的透视方向和视觉效果。**
