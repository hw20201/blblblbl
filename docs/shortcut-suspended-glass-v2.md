## 按用户截图重新调整

### 1. 悬空不是飞起

B 调校模式的卡片目标始终 `offsetX=0、offsetY=0、scale=1`。按下不会整体向上飞，也不突然放大。静止时增加小范围、低透明度的外侧半影，独立画在固定槽位，内部镂空、不画第二张实体卡片。半影是缓存参数的细阶梯近似，不是原生实时高斯阴影，仍需真机检查是否足够柔和。

倾斜卡片的 native shadowElevation 关闭，避免倾斜顶点和高 elevation 联合产生截图中黑厚底座。

### 2. 四边倾斜

B 由原先最大 1.25°改为最大 6°，相机距离从约497dp改为160dp，提高四边透视可见度。按上/下、左/右对应反向倾斜；持按直接跟随触点，不再依赖不断重定向的85ms倾角补间。释放用0.9阻尼回正。中心按压不产生旋转或平移。以上是设计数值，不是“已真机证实满意”。

点击/手势挂在固定外层槽位，内层只旋转玻璃与图标。竖滑优先、横向锁定、取消点击和多指仲裁代码保持原样。水平拖动原有最多4dp跟手仍保留，不是自由拖拽。A/C 参数不改。

### 3. 材质同源底部滑钮，但不要求一模一样

新快捷材质实际复用 `NAVIGATION_LENS_SHADER`，不是只参考截图加一条白边：保留其边缘二次折射、RGB色散、场景响应亮边及清透中心。只适配8dp输入扩边和普通档低采样分支。沿用共享的背景显示列表、已有四角homography世界锚定；不录制文字/图标，不做第二次透视投影。

不再对新快捷材质使用旧27采样高斯磨砂、压凹清晰触点或整面凸透镜。背景、底部滑钮本身没有修改。

### 4. 设置新增“快捷卡片玻璃明显度”

位置：设置 → 快捷卡片玻璃明显度（在快捷触感附近）。即时生效并持久保存，默认普通，未知值安全回退普通。只影响快捷卡片。

| 参数 | 普通 | 明显 | 极致 |
|---|---:|---:|---:|
| 折射位移 | 1.2dp | 2.2dp | 4dp |
| 曲面边缘范围 | 7dp | 9dp | 12dp |
| 色散强度（无量纲） | **10.0** | 15.5 | 20.0 |
| 对应通道位移上限 | .24dp（单侧近似） | .682dp | 1.6dp |
| rimGain | .030 | .045 | .060 |
| 表面淡涂层alpha | .045 | .065 | .080 |

三档不仅改变透明度。明显/极致逐步增加折射宽度、位移、反光与色散；倾斜动作独立，不因普通档而变弱。

### 5. 开销边界

普通档保留色散强度10.0，以单侧额外红通道采样近似轻微色散；平坦中心无论哪个档位均只需一个主场景采样。普通边缘至多主采样+红通道+轮廓采样3次，明显/极致边缘至多4次。色散10.0是原材质的无量纲强度，通过`displacement * clamp(dispersion * .02, 0, .4)`映射，普通边缘通道错位最多约.24dp，不是10dp。旧9tap*RGB路径最坏27次不再用于新材质。

滤镜按尺寸/密度/档位缓存，不随触摸或背景每帧重新创建。扩边从原24dp降为8dp；极致最大位移4+色散1.6+轮廓2=7.6dp仍小于8dp。没有新增待机时钟、动画、逐帧截图或第二个背景录制。

**不承诺具体省电比例**：当前背景本来就在动态绘制，24条低alpha轮廓半影也有开销；本补丁没有改全屏背景的刷新策略。明显和极致采样条数相同，极致曲面范围更大，不代表它必然按比例更耗电。需真机GPU/功耗测量。

API33+真折射；API31/32透明背景重放与壳层降级；API26–30/低内存为静态外观降级。低版本不能获得同等实时折射。
