# 快捷卡片毛玻璃：本地调参实验

以最新确认的 **边缘清晰度 0.55、回弹 0.78** 为准。只改变快捷卡片的材质与 B 跟手倾斜的数值；A/B/C 选择、设置存储、点击、取消、编辑删除和实时触点跟踪仍走原来的路径。

实验基于本地 `9c3e61be7fd7597d2ac9ca2d1cce6809a967410d`，其父提交是已接受的 `a99efd6f84f51183cf7c97e9919b11291ea22def`。独立工作区为 `/workspace/nexus-tuned-frost`，分支为 `experiment/shortcut-tuned-frost-local`；原工作区和两个基线均保留。没有推送、合并、APK、Draft 或发布操作，也没有新增依赖、升级 Compose 或修改核心/网络/安全代码。

## 看到的效果

接触时不做背景模糊；已有的有限手势动画把卡片抬离后，仅卡片采样的背景逐渐柔化。前景文字和图标在独立内容层中绘制，不进入滤镜。边缘折射沿同一个圆润超椭圆轮廓弯曲，清晰度只减少边缘的局部模糊，不添加固定亮色描边。

保持原应用“抬起卡片”的手势约定，而不是把网页的屏幕坐标平移直接复制过来。B 的移动点仍实时更新，初始接触不继承光学折射的即时反馈最低值；模糊只跟随实际分离量。松手清除按压状态，但保留最后触点直至回弹完成，避免镜片突然跳回中央。系统减少动态效果、关闭动画和编辑状态仍遵守原控制语义。

## 参数如何换算

网页参考卡片高度是 190 CSS px，应用快捷卡片是 118dp。几何长度使用 `118 / 190 ≈ 0.621053` 的比例，再按屏幕 density 转成着色器像素，不使用手机截图的物理像素宽度反推数值。

| 用户参数 | Android 实验值与含义 |
|---|---|
| 圆角 60 | 37.263dp，最大不超过卡片短边一半；Compose 裁剪、阴影轮廓与 shader 使用同一超椭圆参数 |
| 超椭圆 2.4 | 无量纲指数 2.4，保留；先归一化再求幂，法线在 dp 空间计算 |
| 折射厚度 54 | 33.537dp；按既有按压量有限增厚，不改变卡片布局高度 |
| 折射系数 2.00 | 无量纲 2.00 |
| 背景距离 0.100 | 无量纲 0.100；原参考的 80 CSS px 光路尺度同步换成 49.684dp，不把 0.100 当成 dp |
| 色散 14.0 | 无量纲；映射为 0.28 的 RGB 采样比例，限制在 0–0.35。**不是 14dp 的通道位移** |
| 菲涅尔 0.22 | 保留；沿折射厚度平滑衰减，沿用参考的 0.42 混合权重 |
| 边缘带宽 32 px | 19.874dp，只定义附加边缘折射与局部清晰区 |
| 边缘折射 0.80 | 无量纲 0.80；当前参数下附加边缘位移约 3.345dp，指数平滑限幅，硬上限不超过 11.179dp |
| 边缘清晰度 **0.55** | 保留；完全抬起时，边缘核尺度从内部的 3dp 减少到约 1.35dp，向内部连续过渡 |
| 模糊 3.0 | 浏览器的 mip LOD 不是 Android blur radius。采用约 3dp sigma 的有限 9 点二维核作为本地视觉校准，**并非浏览器像素级等效** |
| 饱和度 1.04 | 保留为 1.04 倍 |
| 白色遮罩 0.04 | 保留；不再叠加旧版额外 polish/tint，以免重复泛白 |
| 颗粒 0.052 | 保留；确定性 dp 坐标噪声，不新增噪声动画或定时器 |
| 抬升高度 2.0（B） | 1.242dp；沿用应用抬离背景的方向 |
| 缩放 1.004（B） | 无量纲 1.004 |
| 倾斜角度 9°（B） | 上限 9°，按实时触点的归一化 x/y 分别作用 |
| 阴影 12（B） | 7.453dp，仍为独立阴影，不将文字模糊来模拟阴影 |
| 回弹 **0.78（B）** | Compose spring 的 dampingRatio=0.78；并非 0.78 秒 |

A 轻按浮起与 C 浮力回弹保留各自既有动作值；不覆盖用户已选的触摸样式或偏好。透视距离由网页 800 CSS px 同比例映射为约 496.842dp，避免把旧的近距离相机与新的 9° 倾斜组合成夸张拉伸。

原有基础折射位移保留约 9.005dp 的参考上限；附加边缘位移受带宽约束，过渡使用 smoothstep 和平滑饱和，防止窄带或高密度环境产生断层。圆角的可见裁剪由 Compose 轮廓统一负责，不再额外叠一份不同的圆形裁剪。

## 原生实现和退化路径

- **Android 13 / API 33 及以上**：使用现有共享背景场景作为单一 AGSL 输入。接触时不模糊，抬起后每个通道最多 9 次背景采样，包含局部清晰度、折射和色散；整个 shader 最多 27 次采样，接触时通常为 3 次。核权重合计为 1，不通过额外曝光把边缘“画亮”。
- **API 31/32，或现有共享质量档**：不能使用这份 RuntimeShader。保留原生 RenderEffect 背景模糊与绘制式轮廓。其 blur-radius 约定与有限核 sigma 不同，单独使用 6dp 半径校准；没有完整色散与光学边缘清晰度，不能声称与 API 33 路径等效。
- **API 26–30、低内存 Flat 档、软件 Canvas**：保留现有绘制式退化，不假装提供真实后景折射/高斯模糊。不为了补齐退化路径升级 Compose 或加入第三方库。

没有新背景捕获、位图读取、轮询或空闲动画。背景仍使用原来的共享录制源，每个卡片只在形状、主题或有限触摸状态改变时更新自己的效果。不过新增光学采样有 GPU 成本；本地 Robolectric 不能证明真机帧率、功耗或热表现。

## 对比预览与测试

原生 Compose / Robolectric Native Graphics 测试直接调用生产 GlassSurface 与实际 Dashboard，不是 HTML 示意图，也不是手工重绘。静态场景含细条纹、横向细节和背景文字；Dashboard 固定原有 mesh 的时间与 seed，避免动画差异冒充材质差异。

输出位置：

- `app/build/outputs/tuned-frost-static/api35/`：详细静态纹理的浅/深色接触、半抬、抬起、复位，以及旧材质抬起对照。
- `app/build/outputs/tuned-frost-static/api31/`：旧 Android 原生退化路径。
- `app/build/outputs/tuned-frost-dashboard/`：A/B/C 的浅/深色 Dashboard 新旧材质与接触/半抬/抬起/复位。

像素断言检查卡片外区域不变、前景不被背景滤镜污染、接触与复位一致、抬起后的背景细节降低。旧的 8dp 毛玻璃实验测试通过显式关闭本地新材质开关继续作为基线测试，不把旧预期偷偷替换为新参数。

最终编译与测试结果以随附的本地验证摘要和日志为准。所有预览都是软件原生渲染证据，仍需实际 Android GPU 上验收边缘观感与手感。
