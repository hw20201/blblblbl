# V97 界面细节修订

基于 V96。包名、versionCode（87）、versionName 与 V96 相同，仍是 ARM64 Debug 私有测试包，没有做版本号提升。

## 改动

1. **IP 测试的「测试模式」下移**：复选框移到「检测详情」之后，说明文字为「验证 API · 不消耗实时额度」。默认关闭；勾选/取消本身不发起任何查询，查询逻辑未改。
2. **快捷面板收起落点**：FingerTilt 静止时玻璃比命中槽位高 6dp，旧版收起动画按槽位坐标落地，卡片恢复时又向上跳一次。现在共享静止姿态，收起落在卡片真正的静止位置。动画曲线、速度、按压和编辑拖动保持原样。
3. **首页模式切换改为横向「规则｜全局｜直连」**：固定高度 48dp、最大宽度 264dp，三项常驻；滑钮横向移动，页面其余内容位置不变。语义为 RadioButton；重选当前模式不触发回调，也不震动。
4. **上下栏局部染色与折射**：新增 `NavigationLensContent`，把文字/图标作为一份前景交给着色器，只在玻璃实际覆盖的像素内变蓝并轻微放大折射（放大约 4–11%，边缘轻微弯折），覆盖之外保持原色；用替换采样，不会出现原图标与折射图标的双影。顶栏与底栏共用，蓝色统一取 `IosBlue`。

## 库复用

核对了 quven-glass 的 SegmentedTrack/SegmentedControl 与 Glasmio（锁定 0.1.3）的 GlassControls 源码。两者都是把「普通层」与「选中层」分别绘制再用胶囊轮廓裁切；Glasmio 的选项内容只有整项选中/未选中，无法做到半个字被染色。因此沿用项目已有的 Glasmio 外壳材质与 Arca 导航透镜运动，借鉴其「独立前景 + 轮廓遮罩」的做法，自己实现前景层；没有升级依赖，也没有引入新的库。详见 validation/library-reuse.md。

## 验证

- 全量单元测试：174 套件 / 677 用例 / 0 失败 / 0 错误 / 1 跳过（既有的 Android 13 接触 shader 用例）。
- 新增 `NavigationLensContentTest` 5 项：直接经 RenderNode → HardwareRenderer → ImageReader 读取像素，覆盖同一字形一半蓝一半灰、蓝色前沿随滑钮增长、圆角外不染色、放大后无旧笔画残影、48/64dp 轨道取整几何。
- 模拟器（Android 35、x86_64 预览构建，同一份 Kotlin 源码）：已看到首页新选择栏、顶栏与底栏在按住拖动、停在两项之间时的半覆盖染色，以及 IP 面板中测试模式位于结果下方。
- 模拟器验证使用本地假凭据，仅用于界面，已在面板里删除；未发起任何网络查询，也未启动 VPN。

## 未验证的事项

- 没有在真机上运行 ARM64 包，也没有验证 VPN 内核；模拟器只证明界面。
- API 26–32 走局部染色 + 放大的降级路径（无 AGSL 折射），只有代码与几何测试，没有在对应系统版本上看过画面。
- 快捷面板收起手感以连续帧测试（含此前确实失败过的一例）证明落点一致，未做真机录像对比。
- 此前已存在、不在本次范围内的问题未处理（如策略页重复 key 的边界、路由失效时的 VPN 布尔状态、页脚重叠）。
