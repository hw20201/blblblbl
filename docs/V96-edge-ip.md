# V96 改动说明（基于 V95）

## 修复（V94 审查发现）
- 策略页节点行的 lazy key 在同名节点重复时会崩溃：LIST 模式（`proxyGroupRowKeys`）与分页模式（`proxyRowKeysOf`）都改为带出现序号的唯一 key，新增 `ProxiesDuplicateNamesTest`。
- 7890 代理端口提成命名常量；日志字段优先级变化保持原样（适配 JNI 格式）。
- V95 中 `http://ip-api.com` 被网络安全配置拦截（只靠备用源碰巧出结果）：现仅对精确域名 ip-api.com 放行明文，并有配置测试。

## 任务书 A：主页快捷面板玻璃边缘
- 所有快捷面板（IP、配置文件、请求、DNS、规则、分应用、核心日志…）复用 `SettingsDetailEdgeViewport`：标题固定清晰，内容滑过标题时渐进模糊，底部渐隐、末项可滚到清晰区；去掉了硬分割线。
- 节点面板保持 LazyColumn，用列表位置驱动边缘效果；搜索框属于固定头部。

## 任务书 B：API 入口固定
- `ShortcutMorphOverlay` 新增 `pinnedOverlay` 槽：入口画在面板自己的层，不随滚动/内容动画移动；面板完全展开后才出现，开始收起即隐藏。
- 模拟器实测：未检测 / 出结果 / 滚动中 / 滚到底，入口边界恒为 [688,1917][1001,2043]。

## 任务书 C：免费 IP 检测（数据层加固）
- 出口两路竞速（ip-api 带 fields，geojs 备用），整体 8 秒，败者连同 OkHttp Call 取消；GeoJS Unknown/AS0 按未知。
- Scamalytics 网页：按 `<tr>/<th>/<td>` 解析，分数只认 0–100 整数，验证码/拒绝/空页/IP 不匹配判失败，响应体 ≤1 MiB，风险阶段 8 秒。
- 已配置凭据只走官方 API；凭据读取失败（`CredentialLoadState.Unreadable`）不再被当成未配置，直接提示重新配置。
- 结果展示精简：大号 IP + 地点/运营商，风险分与等级做成两个数字块，命中项做成标签，未命中/未知各折叠为一行，并标注“公开网页/官方 API”。

## 其它界面
- 「添加配置」底单：玻璃随圆角、拖动条移入玻璃内；输入框改浅色；主按钮用标准按钮。
