# 快捷卡片悬浮与表面反光修复

## 基准与范围

- 源码基准：`c4451affba509e18289c7ddcf11095f4a201d03b`（main，1.0.32-with-suspended / 37）。
- 这是在已合入 suspended-glass 的 main 上应用的一份增量补丁，**不要再次叠加旧悬空补丁**。
- 不假定可直接应用于 `review/shortcut-jelly-v3-tilt-refinement` 的 1.0.33 / 38；其手势实现不同，需另行移植和验收。
- 不改版本、依赖、签名、权限、VPN、原生库、背景录制、底部导航或三档玻璃设置；未推送/发布。

## 1. 修复编辑排序的矩形灰底

Dashboard 外层原先启用 `shadowElevation = 24f`，却未指定 shape。Compose 默认以矩形 outline 投影；子层已有圆角 clip 不能改变祖先投影。此处 24f 是物理像素，也不是 24dp。

修复后外层只负责排序位置、zIndex 与轻微缩放，阴影为零。编辑拖拽状态传入卡片；卡片统一解析最终形状，让原生阴影与玻璃裁剪使用同一个 shape（默认实际圆角约 37.26dp，并非硬编码18dp）。原生 caster 不裁切，材质层继续圆角裁剪；保留8dp光学采样扩边，避免用裁切阴影掩盖错误。

编辑拖拽缩放由1.06降至1.025。背景重放仍只取共享背景，不包含前景文字或其他应用窗口。

## 2. 补上常态悬空线索

使用 Android/Compose 原生 outline 阴影：常态3dp、按压3→5dp、编辑排序8dp，降低 ambient/spot alpha。阴影随实际卡面移动，不保留固定实体底卡。Dock关闭的旧材质比较路径互斥，避免叠两层caster；非玻璃皮肤保留原有样式。

删除旧的、当前main本来就未调用的24层轮廓伪半影函数。此前文档对该函数的描述不代表本基准的运行路径。

注意：原生阴影仍是硬件渲染效果，不等于已经消除所有设备上的内部压暗或厚底座观感。API26–27不支持同等自定义阴影颜色控制；这些需要真机验收。

## 3. 重心倾斜更明确，但不飞起

仅默认Dock材质的B模式使用新权重：`n * (1.8 - 0.8*abs(n))`，再按二维向量限制合计倾角不超过6°。中区更灵敏，角点不再同时把两轴推到6°；中心保持中性，scale=1，不加整体上移。

持按直接跟随，释放沿现有有限回弹恢复；固定槽位负责命中，实际卡面负责变换。普通手势仲裁、长按拾起、点击取消、多指处理未重写。

`cameraDistance` 是卡片3D倾斜的**虚拟透视距离**，不是手机摄像头；按 `max(160dp, 卡宽*0.84)` 设置，减轻原100dp透视导致的近边膨胀。不调用摄像头、不申请权限。

## 4. 表面反光随真实倾角变化

在 `ShortcutRefraction` 尾部增加带默认值的pitch/roll；从实际可见角度读取，覆盖持按和释放。Dock表面将固定亮边改为约1.2dp的方向高光和对侧暗边；反光方向连续变化，无零向量翻转缝。仅表面轮廓绘制变化，文字/图标仍是滤镜外的最后清晰层。

这是**程序化方向反光线索**，不是拍摄环境反射、环境贴图或真实光线追踪。已有AGSL背景折射、色散和世界坐标锚定保持不变，不能把此修改称为完整物理反射引擎。未新增场景采样、模糊、位图截屏或待机时钟；动态渐变和原生阴影仍有开销，不承诺省电比例。

## 真机重点验收

1. 浅/深色进入编辑，长按任一卡片跨行跨列移动：不得再出现矩形投影轮廓；取消/释放恢复，不能误触VPN。
2. B模式静止有轻微离地感，中心不飞起；靠近上下左右时方向一致、反光跟随，释放连续回正。
3. 确认没有厚重黑底座、阴影内透压暗、低版本异常或网格/视口边缘硬裁切。
4. 玻璃普通/明显/极致、非玻璃、API26–30/31–32/33+分别核验。API33以下仍不是等价实时折射。
